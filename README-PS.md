# د اسحاقزاده خپلواک سټور

دا نسخه د ChatGPT ننوتلو ته اړتیا نه لري. تر اوسه ستا شخصي سرور ته نه ده نښلول شوې او عامه نه ده خپره شوې.

۱. Supabase په خپل nk6341350@gmail.com حساب خلاص کړه او د سټور لپاره یوه فعاله پروژه وټاکه. د پخوانۍ پروژې معلومات مه حذفوه.
۲. په Authentication > Users کې خپل ایمیل د پاسورډ سره جوړ او تایید کړه. پاسورډ یوازې خپله وساته. د نورو کسانو د نوم‌لیکنې اختیار بند کړه.
۳. په نوې پروژه کې setup.sql یو ځل اجرا کړه. دا ستا حساب اډمین کوي. د تکرار یا خطا په صورت کې جدولونه مه حذفوه؛ خطا وڅېړه.
۴. په config.js کې د پروژې URL او عام Publishable/anon key ولیکه. Secret یا service_role key مه ور اچوه.
۵. د deploy فولډر منځپانګه د خپل Cloudflare Pages حساب ته پورته کړه. دا نسخه Worker ته اړتیا نه لري.
۶. مشتریان سټور بې حسابه ګوري؛ ته د اډمین تڼۍ له لارې د سټور په ایمیل او پاسورډ ننوځې.

د راتلونکي اصلاح لپاره ټول ZIP په خپل موبایل/کمپیوټر او خپل GitHub کې وساته. په هر نوي چټ کې ZIP یا د کوډ لینک او HANDOFF.md ورکړه.

دغه ZIP د کوډ نقل دی؛ وروسته ثبت شوي جنسونه او عکسونه جلا بیک‌اپ ته اړتیا لري. د وړیا خدمتونو حدود شته، د تل لپاره وړیا او بې وقفې کار ضمانت نشته.
